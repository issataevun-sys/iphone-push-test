1. Подписка iPhone

Откройте сайт через Safari → «Поделиться» → «На экран Домой», затем запустите с иконки.

2. Отправка тестового push

Нажмите «Скопировать подписку». Вставьте результат в GitHub → Settings → Secrets and variables → Actions как секрет PUSH_SUBSCRIPTION. После этого запустите GitHub Actions → Send test push.

Подписка содержит приватный адрес доставки. Не публикуйте её в открытом репозитории или переписке.
