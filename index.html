🔔 iPhone Push Test

Проверка настоящих Web Push, в том числе при закрытом приложении и заблокированном экране.

1. Статус

Загрузка…

2. Подписка

На iPhone откройте сайт в Safari → «Поделиться» → «На экран Домой». Запустите приложение с иконки и разрешите push.

3. Отправка

После подключения отправьте тестовый push из панели OneSignal → Messages. Для отправки через Google Apps Script есть отдельный пример в репозитории.

GitHub Pages размещает приложение, OneSignal доставляет уведомления. API-ключ нельзя публиковать в коде сайта.
